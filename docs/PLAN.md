# MoonHlog 实现计划

目标是让 MoonBit 项目读写和比较 HdrHistogram 的压测日志。库处理日志格式与统计，CLI 负责本地文件和 CI 退出状态。

1. 对照 HdrHistogram Java 的日志读写和分位数定义，实现日志区间、标签、时间基准与压缩整数直方图 V2 的解码。支持相同布局的直方图合并和明确的输入错误。
2. 实现可交换的 V2 编码，以及 `summary` 和 `compare` 命令。比较前筛选标签或时间窗口。比较基于合并后的计数，各次运行采用相同的时间域。
3. 以 Java 生成的日志作为独立对照，验证解码、计数、合并与分位数。核对 MoonBit 写出的日志可由 Java 读取。再验证 CLI 的正常、超阈值和输入错误退出码。
4. 写 README、评委演示和一页项目申报书。申报书沿用 MoonTrace 对齐官方样例后的四节结构，以实际完成的验证填充。将代码和文档推到新的公开 GitHub 仓库，核对远端提交和 CI。
